[제출물 ③] 성찰일지 — SDD 레거시 확장 프로젝트

이름: 이규환
확장한 기능: 추천 이유 문장 출력 (중간 난이도)

■ 무엇을 더했고 어떻게 검증했는지

기존 강원생활도우미앱의 검색 결과에, 각 장소를 왜 추천하는지 설명하는 문장을
붙여주는 make_reasons 함수를 새로 추가했다. 기존 함수(load_data, join_data,
filter_recommendations)는 한 줄도 수정하지 않았고, 새 함수는 검색 결과를
copy()해서 쓰기 때문에 원본 데이터도 바뀌지 않는다.

검증은 두 방향으로 했다. 신규 검증은 결과 문장을 미리 손으로 쓸 수 있는
1행짜리 테스트 데이터를 만들어, 함수 출력이 내가 예측한 문장과 글자 단위로
일치하는지 True/False로 판정했다. 회귀 검증은 확장 전에 박제해 둔 기준
(강릉/휴식/맑은날/친구/1만원 검색 → 3곳)이 확장 후에도 그대로인지 확인했다.
둘 다 통과했다.

■ 개발 후기

AI에게 기존 코드 설명을 시켰을 때 예산 조건을 "같음"이라고 잘못 설명한 걸
직접 코드를 읽고 잡아낸 게 가장 기억에 남는다. AI가 만든 코드도 그대로 믿지
않고, 검증 기준과 테스트 데이터는 내가 만들어서 확인했다. 기능 자체는 단순하지만
명세 → 기존 보호 → 검증 순서를 지키니까 "고치다가 깨뜨리는" 일 없이 확장할 수
있었다. 접점 명세에서 새 함수가 의존하는 열 5개를 미리 적어 둔 덕분에 테스트
데이터도 최소한으로 만들 수 있었다는 점이 배운 점이다.

■ 시연

앱 실행 화면(기존 검색 + 추천 이유 보기 체크박스)은 스크린샷으로 첨부.
